
# 🎓 AI Study Assistant

## Project Overview
AI Study Assistant is an AI-powered educational application that helps students understand study topics and get answers to their questions using Google Gemini AI.

## Features
- Ask any educational question.
- Generate AI-powered answers.
- Simple and user-friendly interface.
- Secure API key input.
- Fast responses using Gemini AI.

## Technologies Used
- Python 3.12
- Streamlit
- Google Gemini AI
- Google GenAI SDK
- Visual Studio Code

## Installation

### Step 1: Clone the project
git clone YOUR_GITHUB_REPOSITORY_URL

### Step 2: Open project folder
cd AI-Study-Assistant

### Step 3: Create virtual environment
python -m venv .venv

### Step 4: Activate environment
.venv\Scripts\activate

### Step 5: Install libraries
pip install -r requirements.txt

### Step 6: Run application
streamlit run app.py

## API Key Setup
1. Get your Gemini API key from Google AI Studio.
2. Run the application.
3. Enter your API key in the sidebar.
4. Ask your study question.
